# Question 02 — MTN Uganda Website

A multi-page MTN Uganda web design practical built with HTML5 and external CSS.

## Pages and files
- `index.html` — homepage and service cards
- `bundles.html` — data bundles page
- `style.css` — shared external stylesheet

## Run locally
Open `index.html` in a browser. Keep the HTML and CSS files in the same folder.
